## 🦸‍♀️ Answers from File 01: Superhero Match-Up
1. **Carbon (C)** — Under immense pressure inside the Earth, carbon atoms arrange in a 3D crystal lattice forming diamonds.
2. **Helium (He)** — Helium is much lighter than air ($N_2 + O_2$), so balloons rise! It makes vocal cords vibrate faster, creating a squeaky high pitch.
3. **Calcium (Ca)** — Gives structure to bones, teeth, and seashell shells.
4. **Silicon (Si)** — A semiconductor found in quartz/sand, crucial for computer processors.
5. **Chlorine (Cl)** — Sodium ($Na$) + Chlorine ($Cl$) = Sodium Chloride ($NaCl$), standard table salt!

## 🧩 Answers from File 03: Puzzles, Riddles & Quiz

### Round 1: Secret Agent Chemical Word Decoder
#### Part A:
1. $C + Ar$ = **CAR**
2. $Na + P$ = **NAP**
3. $Ca + Te + Rn$ = **CATERN** (or $Ca + F + E$ = **CAFE** / $Ca + Fe + Te + R + I + A$)
4. $W + Ag + S$ = **WAGS**
5. $B + O + S + S$ = **BOSS**
6. $C + O + O + La$ = **COOLA** / **COOL**
7. $P + I + Zr + Zr + Al$ = **PIZZA** (or $P + I + Z + Z + A$)

#### Part B: Element Name Detective
1. **$TaCo$**:
   * $Ta$ = **Tantalum** (#73)
   * $Co$ = **Cobalt** (#27)
2. **$LiOn$**:
   * $Li$ = **Lithium** (#3)
   * $O$ = **Oxygen** (#8)
   * $N$ = **Nitrogen** (#7)
3. **$ScIEnCe$**:
   * $Sc$ = **Scandium** (#21)
   * $I$ = **Iodine** (#53)
   * $E$ (or $Es$) = **Einsteinium** (#99) / $N$ = **Nitrogen** (#7) / $Ce$ = **Cerium** (#58)

### Round 2: "Who Am I?" Mystery Element Riddles
1. **Hydrogen** | Symbol: **H** | Atomic #: **1**  
   *Explanation: $H$ is element #1, makes up 75% of universe mass and combines with $O$ to make $H_2O$.*
2. **Carbon** | Symbol: **C** | Atomic #: **6**  
   *Explanation: Pencil graphite and diamonds are both 100% pure carbon!*
3. **Nitrogen** | Symbol: **N** | Atomic #: **7**  
   *Explanation: Earth's atmosphere is 78% Nitrogen. Chip companies pump $N_2$ into bags so chips stay crunchy and don't get crushed!*
4. **Sodium** | Symbol: **Na** | Atomic #: **11**  
   *Explanation: Pure sodium reacts with moisture to form hydrogen gas and heat, but $NaCl$ is table salt.*
5. **Potassium** | Symbol: **K** | Atomic #: **19**  
   *Explanation: Found in high amounts in bananas, essential for neuron and muscle signaling.*
6. **Neon** | Symbol: **Ne** | Atomic #: **10**  
   *Explanation: Noble gas that emits orange-red light when excited with electric voltage.*

### Round 3: Periodic Table Trivia Showdown
1. **B) The number of protons inside the atom's center**  
   *The atomic number defines what element an atom is. If it has 6 protons, it's ALWAYS Carbon!*
2. **B) Hydrogen and Oxygen**  
   *Water is $H_2O$ (two Hydrogens, one Oxygen).*
3. **C) They are super stable and almost never react or bond with other elements**  
   *Their outer electron shells are completely full, so they don't need to gain or lose electrons.*
4. **B) Iron (Fe)**  
   *Iron binds oxygen molecules in hemoglobin inside your red blood cells.*
5. **A) Fluorine (F)**  
   *Fluoride ions replace hydroxyl ions in tooth enamel, making teeth resistant to acid decay.*
