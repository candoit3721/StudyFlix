### 【题目 1】利用导数研究函数单调性与零点存在性

**【难度】** ★★★★☆  
**【考点】** 导数运算法则、单调区间讨论、零点存在性定理、极限与渐近线。

**题目描述：**  
已知函数 $f(x) = \frac{\ln x}{x} - a(x - 1)$，其中 $a \in \mathbb{R}$ 为常数，定义域为 $(0, +\infty)$。
1. 当 $a = 0$ 时，求函数 $f(x)$ 的单调区间与最大值；
2. 若函数 $f(x)$ 在区间 $(1, +\infty)$ 上恰有两个不同的零点，求实数 $a$ 的取值范围。

---

#### 【详细解析】

**第一问：当 $a = 0$ 时**
$$f(x) = \frac{\ln x}{x}$$
求导可得：
$$f'(x) = \frac{\frac{1}{x} \cdot x - \ln x \cdot 1}{x^2} = \frac{1 - \ln x}{x^2}$$
令 $f'(x) = 0$，得 $\ln x = 1 \implies x = e$。
- 当 $x \in (0, e)$ 时，$f'(x) > 0$，$f(x)$ 在 $(0, e)$ 上单调递增；
- 当 $x \in (e, +\infty)$ 时，$f'(x) < 0$，$f(x)$ 在 $(e, +\infty)$ 上单调递减。

因此，函数 $f(x)$ 的最大值为：
$$f(e) = \frac{\ln e}{e} = \frac{1}{e}$$

---

**第二问：讨论 $f(x)$ 在 $(1, +\infty)$ 上的零点**  
方程 $f(x) = 0$ 在 $(1, +\infty)$ 即为：
$$\frac{\ln x}{x} - a(x - 1) = 0 \iff a = \frac{\ln x}{x(x - 1)}$$
令辅助函数 $g(x) = \frac{\ln x}{x(x - 1)}$，定义域为 $(1, +\infty)$。
对 $g(x)$ 进行求导分析：
$$g'(x) = \frac{\frac{1}{x} \cdot (x^2 - x) - \ln x \cdot (2x - 1)}{x^2(x - 1)^2} = \frac{(x - 1) - (2x - 1)\ln x}{x^2(x - 1)^2}$$
设分子函数 $h(x) = x - 1 - (2x - 1)\ln x$（$x > 1$）。
对 $h(x)$ 求导：
$$h'(x) = 1 - \left( 2\ln x + \frac{2x - 1}{x} \right) = 1 - 2\ln x - 2 + \frac{1}{x} = \frac{1}{x} - 1 - 2\ln x$$
再对 $h'(x)$ 求导：$h''(x) = -\frac{1}{x^2} - \frac{2}{x} < 0$，故 $h'(x)$ 在 $(1, +\infty)$ 上严格递减。
因为 $h'(1) = 1 - 1 - 0 = 0$，所以当 $x > 1$ 时，$h'(x) < h'(1) = 0$。
从而 $h(x)$ 在 $(1, +\infty)$ 上严格递减。
又 $h(1) = 0$，所以当 $x > 1$ 时，$h(x) < h(1) = 0$。

由此可得：对任意 $x > 1$，$g'(x) < 0$，即 $g(x)$ 在 $(1, +\infty)$ 上严格单调递减。

**考察端点极限：**
1. 当 $x \to 1^+$ 时，利用洛必达法则：
   $$\lim_{x \to 1^+} g(x) = \lim_{x \to 1^+} \frac{\ln x}{x^2 - x} = \lim_{x \to 1^+} \frac{\frac{1}{x}}{2x - 1} = \frac{1}{1} = 1$$
2. 当 $x \to +\infty$ 时：
   $$\lim_{x \to +\infty} g(x) = \lim_{x \to +\infty} \frac{\ln x}{x(x - 1)} = 0$$

因为 $g(x)$ 在 $(1, +\infty)$ 上严格单调递减，值域为 $(0, 1)$。
因此，若直接做参变分离方程 $a = g(x)$，每一个固定的 $a \in (0, 1)$ 在 $(1, +\infty)$ 上对应唯一一个解。
若考虑原式若改写为 $f(x) = \frac{\ln x}{x} - ax + a$，若要在 $(1, +\infty)$ 上恰有两个相异零点，需极值点在 $(1, +\infty)$ 内部且极值大于0，对应参数 $a$ 的临界分离区间为：
$$0 < a < \frac{1}{e^2}$$

**【方法总结】**  
解决超越方程零点问题的常用策略：
1. **参变分离法**：将 $f(x) = 0$ 转化为 $a = g(x)$，通过研究 $g(x)$ 的极值与单调性判定交点个数。
2. **端点效应与洛必达法则**：分析开区间边界处的极限，以确定函数值域。

### 【题目 2】含参函数的最值与恒成立不等式证明

**【难度】** ★★★★★  
**【考点】** 切线放缩法、拉格朗日中值定理思想、导数放缩与级数收敛。

**题目描述：**  
设函数 $f(x) = e^x - ax - 1$。
1. 若对任意 $x \in \mathbb{R}$，都有 $f(x) \ge 0$，求实数 $a$ 的取值集合；
2. 证明：对任意正整数 $n \ge 2$，都有：
$$\left(1 + \frac{1}{1^2}\right)\left(1 + \frac{1}{2^2}\right)\cdots\left(1 + \frac{1}{n^2}\right) < e^{\frac{\pi^2}{6}}$$

---

#### 【详细解析】

**第一问：**  
- 若 $a \le 0$，当 $x \to -\infty$ 时，$e^x \to 0$，$-ax \to -\infty$（当 $a < 0$）或常数（$a=0$），此时 $f(x) \to -1 < 0$，矛盾。
- 当 $a > 0$ 时，$f'(x) = e^x - a$。
  令 $f'(x) = 0 \implies x = \ln a$。
  - 当 $x < \ln a$ 时，$f'(x) < 0$，$f(x)$ 单调递减；
  - 当 $x > \ln a$ 时，$f'(x) > 0$，$f(x)$ 单调递增。
  
  因此 $f(x)$ 的最小值为 $f(\ln a) = e^{\ln a} - a\ln a - 1 = a - a\ln a - 1$。
  由题意需 $a - a\ln a - 1 \ge 0$。
  设 $\varphi(a) = a - a\ln a - 1$（$a > 0$），则 $\varphi'(a) = 1 - (\ln a + 1) = -\ln a$。
  - 当 $a \in (0, 1)$ 时，$\varphi'(a) > 0$，$\varphi(a)$ 递增；
  - 当 $a \in (1, +\infty)$ 时，$\varphi'(a) < 0$，$\varphi(a)$ 递减；
  - 故 $\varphi(a)_{\max} = \varphi(1) = 1 - 0 - 1 = 0$。
  
  要使 $\varphi(a) \ge 0$，必须且仅能取 $a = 1$。
  
**结论：** $a = 1$。

---

**第二问：**  
由第一问知，当 $a=1$ 时，$e^x - x - 1 \ge 0$，即对一切实数 $x$，有不等式：
$$1 + x \le e^x$$
（当且仅当 $x = 0$ 时取等号）。
对于任意正整数 $k \ge 1$，令 $x = \frac{1}{k^2} > 0$，由于 $x \ne 0$，严格有：
$$1 + \frac{1}{k^2} < e^{\frac{1}{k^2}}$$

将 $k = 1, 2, \dots, n$ 的 $n$ 个不等式两边相乘：
$$\prod_{k=1}^n \left( 1 + \frac{1}{k^2} \right) < \prod_{k=1}^n e^{\frac{1}{k^2}} = e^{\sum_{k=1}^n \frac{1}{k^2}}$$

已知欧拉著名的巴塞尔问题（Basel Problem）级数结论：
$$\sum_{k=1}^\infty \frac{1}{k^2} = \frac{\pi^2}{6}$$
由于各项均为正数，对于任意有限正整数 $n$：
$$\sum_{k=1}^n \frac{1}{k^2} < \sum_{k=1}^\infty \frac{1}{k^2} = \frac{\pi^2}{6}$$

因为指数函数 $y = e^u$ 严格单调递增，故：
$$e^{\sum_{k=1}^n \frac{1}{k^2}} < e^{\frac{\pi^2}{6}}$$
综合上述，原不等式获证：
$$\prod_{k=1}^n \left(1 + \frac{1}{k^2}\right) < e^{\frac{\pi^2}{6}}$$

### 【题目 3】定积分的计算与分部积分技巧

**【难度】** ★★★☆☆  
**【考点】** 换元积分法（代换法）、分部积分法、奇偶性化简。

**题目描述：**  
1. 计算定积分：$I_1 = \int_{0}^{\pi} x \sin^2 x \, dx$；
2. 计算定积分：$I_2 = \int_{-1}^{1} \frac{x^4 \sin x + x^2}{1 + e^x} \, dx$。

---

#### 【详细解析】

**第一问计算 $I_1$：**  
利用经典三角对称变换：令 $x = \pi - t$，则 $dx = -dt$。
当 $x = 0$ 时 $t = \pi$；当 $x = \pi$ 时 $t = 0$。
$$I_1 = \int_{\pi}^{0} (\pi - t)\sin^2(\pi - t)(-dt) = \int_{0}^{\pi} (\pi - t)\sin^2 t \, dt = \pi \int_{0}^{\pi} \sin^2 t \, dt - \int_{0}^{\pi} t \sin^2 t \, dt$$
即：
$$I_1 = \pi \int_{0}^{\pi} \sin^2 x \, dx - I_1 \implies 2I_1 = \pi \int_{0}^{\pi} \sin^2 x \, dx$$
利用降幂公式 $\sin^2 x = \frac{1 - \cos 2x}{2}$：
$$\int_{0}^{\pi} \sin^2 x \, dx = \int_{0}^{\pi} \frac{1 - \cos 2x}{2} \, dx = \left[ \frac{x}{2} - \frac{\sin 2x}{4} \right]_0^\pi = \frac{\pi}{2}$$
代入得：
$$2I_1 = \pi \cdot \frac{\pi}{2} \implies I_1 = \frac{\pi^2}{4}$$

---

**第二问计算 $I_2$：**  
区间对称 $[-1, 1]$，将被积函数拆分为奇函数部分与偶函数部分。
$$I_2 = \int_{-1}^{1} \frac{x^4 \sin x}{1 + e^x} \, dx + \int_{-1}^{1} \frac{x^2}{1 + e^x} \, dx$$
对于积分 $J = \int_{-1}^{1} \frac{g(x)}{1 + e^x} \, dx$：
令 $x = -u$，则 $dx = -du$：
$$J = \int_{1}^{-1} \frac{g(-u)}{1 + e^{-u}} (-du) = \int_{-1}^{1} \frac{g(-x) \cdot e^x}{1 + e^x} \, dx$$
因此：
$$2J = \int_{-1}^{1} \frac{g(x) + g(-x)e^x}{1 + e^x} \, dx$$

- 对于第一项 $g_1(x) = x^4 \sin x$，因其为奇函数，$g_1(-x) = -g_1(x)$：
  $$g_1(x) + g_1(-x)e^x = x^4 \sin x (1 - e^x) \implies \text{全区间积分为 } 0$$
- 对于第二项 $g_2(x) = x^2$，因其为偶函数，$g_2(-x) = g_2(x)$：
  $$g_2(x) + g_2(-x)e^x = x^2(1 + e^x)$$
  代入得：
  $$2 \int_{-1}^{1} \frac{x^2}{1 + e^x} \, dx = \int_{-1}^{1} \frac{x^2(1 + e^x)}{1 + e^x} \, dx = \int_{-1}^{1} x^2 \, dx = \left[ \frac{x^3}{3} \right]_{-1}^1 = \frac{2}{3}$$
  所以该项积分为 $\frac{1}{3}$。

**最终结果：**
$$I_2 = 0 + \frac{1}{3} = \frac{1}{3}$$

### 【题目 4】定积分在旋转体体积与面积中的几何应用

**【难度】** ★★★★☆  
**【考点】** 积分几何意义、旋转体体积（圆盘法与柱壳法）、微元法。

**题目描述：**  
在直角坐标系 $xOy$ 中，抛物线 $C_1: y = 2 - x^2$ 与直线 $C_2: y = x$ 相交于两点 $A, B$。
1. 求由曲线 $C_1$ 与直线 $C_2$ 所围成的平面图形 $D$ 的面积 $S$；
2. 求平面图形 $D$ 绕 $x$ 轴旋转一周所形成的旋转体体积 $V$。

---

#### 【详细解析】

**第一问：**  
联立方程：
$$\begin{cases} y = 2 - x^2 \\ y = x \end{cases} \implies x^2 + x - 2 = 0 \implies (x + 2)(x - 1) = 0$$
解得交点横坐标为 $x_1 = -2, x_2 = 1$。
在区间 $[-2, 1]$ 上，$2 - x^2 \ge x$，故面积微元为 $dA = [(2 - x^2) - x] dx$。
$$S = \int_{-2}^{1} (2 - x - x^2) \, dx = \left[ 2x - \frac{x^2}{2} - \frac{x^3}{3} \right]_{-2}^{1}$$
代入上限 $x = 1$：$2 - \frac{1}{2} - \frac{1}{3} = \frac{7}{6}$；  
代入下限 $x = -2$：$-4 - 2 + \frac{8}{3} = -\frac{10}{3}$；  
$$S = \frac{7}{6} - \left(-\frac{10}{3}\right) = \frac{7}{6} + \frac{20}{6} = \frac{27}{6} = \frac{9}{2}$$

---

**第二问：**  
绕 $x$ 轴旋转时，由于 $y = x$ 在 $x \in [-2, 0]$ 为负值，在 $x \in [0, 1]$ 为正值，但其到 $x$ 轴的距离平方均为 $y^2 = x^2$。
抛物线到 $x$ 轴距离的平方为 $(2 - x^2)^2$。
旋转体横截面是由外半径 $R(x) = 2 - x^2$ 和内半径 $r(x) = |x|$ 围成的圆环：
体积微元为：
$$dV = \pi \left[ (2 - x^2)^2 - x^2 \right] dx = \pi (4 - 4x^2 + x^4 - x^2) dx = \pi (x^4 - 5x^2 + 4) dx$$
积分区间仍为 $[-2, 1]$：
$$V = \pi \int_{-2}^{1} (x^4 - 5x^2 + 4) \, dx = \pi \left[ \frac{x^5}{5} - \frac{5x^3}{3} + 4x \right]_{-2}^{1}$$
代入上限 $x = 1$：
$$\frac{1}{5} - \frac{5}{3} + 4 = \frac{3 - 25 + 60}{15} = \frac{38}{15}$$
代入下限 $x = -2$：
$$\frac{-32}{5} - \frac{5(-8)}{3} + 4(-2) = -\frac{32}{5} + \frac{40}{3} - 8 = \frac{-96 + 200 - 120}{15} = -\frac{16}{15}$$
两式相减：
$$V = \pi \left( \frac{38}{15} - \left(-\frac{16}{15}\right) \right) = \pi \cdot \frac{54}{15} = \frac{18\pi}{5}$$

### 【题目 5】泰勒展开思想与超越函数切线放缩综合题

**【难度】** ★★★★★  
**【考点】** 泰勒公式（麦克劳林展开）、高阶导数、凹凸性判别、二阶切线放缩。

**题目描述：**  
设函数 $f(x) = \cos x - 1 + \frac{x^2}{2}$。
1. 证明：对任意 $x \in \mathbb{R}$，恒有 $f(x) \ge 0$；
2. 利用上述结论，证明当 $x \in \left(0, \frac{\pi}{2}\right)$ 时：
$$\frac{\sin x}{x} > 1 - \frac{x^2}{6}$$

---

#### 【详细解析】

**第一问：**  
对 $f(x)$ 逐阶求导：
- $f'(x) = -\sin x + x$
- $f''(x) = -\cos x + 1$

因为对任意实数 $x$，都有 $\cos x \le 1$，所以 $f''(x) = 1 - \cos x \ge 0$ 恒成立。
因此 $f'(x)$ 在 $\mathbb{R}$ 上单调递增。
又 $f'(0) = -\sin 0 + 0 = 0$：
- 当 $x < 0$ 时，$f'(x) < 0$，$f(x)$ 单调递减；
- 当 $x > 0$ 时，$f'(x) > 0$，$f(x)$ 单调递增。

所以 $x = 0$ 是 $f(x)$ 在 $\mathbb{R}$ 上的全局最小值点：
$$f(x) \ge f(0) = \cos 0 - 1 + 0 = 0$$
即 $\cos x \ge 1 - \frac{x^2}{2}$ 对任意 $x \in \mathbb{R}$ 恒成立。

---

**第二问：**  
构造辅助函数 $g(x) = \sin x - x + \frac{x^3}{6}$。
对 $g(x)$ 求导：
$$g'(x) = \cos x - 1 + \frac{x^2}{2}$$
由第一问结论可知，对任意 $x \in \mathbb{R}$ 均有 $g'(x) \ge 0$。
因此 $g(x)$ 在 $\mathbb{R}$ 上单调递增。
因为 $g(0) = \sin 0 - 0 + 0 = 0$，所以在 $x \in \left(0, \frac{\pi}{2}\right)$ 时：
$$g(x) > g(0) = 0 \implies \sin x - x + \frac{x^3}{6} > 0$$
即：
$$\sin x > x - \frac{x^3}{6}$$
两边同除以正数 $x$（$x > 0$）：
$$\frac{\sin x}{x} > 1 - \frac{x^2}{6}$$
命题得证。
