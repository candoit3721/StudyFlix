## 🎯 核心知识点与公式速查

### 1. 微积分核心公式
- **常用导数与放缩不等式：**
  - $e^x \ge x + 1 \quad (\forall x \in \mathbb{R})$
  - $\ln x \le x - 1 \quad (x > 0)$
  - $\sin x < x < \tan x \quad \left(x \in \left(0, \frac{\pi}{2}\right)\right)$
  - $\cos x \ge 1 - \frac{x^2}{2} \quad (\forall x \in \mathbb{R})$
- **定积分几何应用：**
  - 平面面积：$S = \int_{a}^{b} [f(x) - g(x)] \, dx$
  - 绕 $x$ 轴旋转体体积：$V = \pi \int_{a}^{b} [f(x)]^2 \, dx$

### 2. 概率与数理统计核心公式
- **离散型随机变量：**
  - 超几何分布期望：$E(X) = n \cdot \frac{M}{N}$
  - 二项分布：$X \sim B(n, p) \implies E(X) = np, \quad D(X) = np(1-p)$
  - 期望与方差性质：$E(aX + b) = aE(X) + b, \quad D(aX + b) = a^2 D(X)$
- **独立性卡方检验统计量：**
  $$\chi^2 = \frac{n(ad - bc)^2}{(a+b)(c+d)(a+c)(b+d)}$$
- **一元线性回归方程：**
  $$\hat{b} = \frac{\sum_{i=1}^n (x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^n (x_i - \bar{x})^2}, \quad \hat{a} = \bar{y} - \hat{b}\bar{x}$$
