## 详细参考答案与评分标准

### 第一部分：单项选择题
1. **【答案】A**  
   **【解析】** $y' = e^{2x} + 2x e^{2x}$。在 $x = 0$ 处，$y'(0) = 1$。切线方程为 $y - 0 = 1(x - 0) \implies y = x$。
2. **【答案】A**  
   **【解析】** 正态分布密度曲线关于对称轴 $x = \mu = 3$ 对称。$P(X > 5) = P(X < 3 - (5-3)) = P(X < 1)$，因此 $c = 1$。
3. **【答案】B**  
   **【解析】** 令 $u = 1 - x^2$，$du = -2x dx \implies x dx = -\frac{1}{2} du$。当 $x=0$ 时 $u=1$；$x=1$ 时 $u=0$。  
   $\int_{0}^{1} x \sqrt{1 - x^2} \, dx = -\frac{1}{2} \int_{1}^{0} \sqrt{u} \, du = \frac{1}{2} \left[ \frac{2}{3} u^{3/2} \right]_0^1 = \frac{1}{3}$。
4. **【答案】A**  
   **【解析】** 设事件 $A$ 为“抽得次品”，$B_1$ 为“甲车间”，$B_2$ 为“乙车间”。  
   $P(A) = P(B_1)P(A|B_1) + P(B_2)P(A|B_2) = 0.6 \times 0.02 + 0.4 \times 0.03 = 0.012 + 0.012 = 0.024$。  
   根据贝叶斯公式：$P(B_2|A) = \frac{P(B_2)P(A|B_2)}{P(A)} = \frac{0.012}{0.024} = \frac{1}{2}$。

### 第二部分：多项选择题
5. **【答案】A, C, D**  
   **【解析】**  
   $f'(x) = 3x^2 - 6x = 3x(x - 2)$。  
   - $x \in (-\infty, 0)$ 时 $f' > 0$；$x \in (0, 2)$ 时 $f' < 0$；$x \in (2, +\infty)$ 时 $f' > 0$。  
   - 极大值为 $f(0) = 2$（A正确）；$(0, 2)$ 上单调递减（B错误）；  
   - $f''(x) = 6x - 6 = 0 \implies x = 1$，$f(1) = 0$，点 $(1, 0)$ 为拐点且为对称中心（C正确）；  
   - 极小值 $f(2) = 8 - 12 + 2 = -2$。因为 $-2 < -1 < 2$，所以水平直线 $y = -1$ 介于极小值与极大值之间，与曲线必有 3 个交点（D正确）。

### 第三部分：填空题
7. **【答案】$1$**  
   **【解析】** 展开或两次洛必达：$\lim_{x \to 0} \frac{e^x - \cos x - x}{x^2} = \lim_{x \to 0} \frac{e^x + \sin x - 1}{2x} = \lim_{x \to 0} \frac{e^x + \cos x}{2} = \frac{1 + 1}{2} = 1$。
8. **【答案】$16$**  
   **【解析】** 回归直线过中心点 $(4, 10)$，方程为 $\hat{y} - 10 = 1.5(x - 4) \implies \hat{y} = 1.5x + 4$。代入 $x = 8$ 得 $\hat{y} = 1.5 \times 8 + 4 = 16$。
9. **【答案】$\frac{4}{3}$**  
   **【解析】** 超几何分布数学期望 $E(X) = n \cdot \frac{M}{N} = 2 \times \frac{4}{6} = \frac{4}{3}$。

#### 第 11 题解答
1. **（10分）**  
   当 $a = 0$ 时，$f(x) = x e^x - \frac{1}{2} x^2$。  
   $f'(x) = e^x + x e^x - x = (x + 1)e^x - x$。  
   令 $g(x) = f'(x)$，则 $g'(x) = e^x + (x + 1)e^x - 1 = (x + 2)e^x - 1$。  
   易知 $g'(0) = 1 > 0$，$g'(x)$ 存在唯一零点 $x_0$，且 $f'(0) = 1 > 0$。  
   通过分析可知 $f'(x) > 0$ 恒成立，因此 $f(x)$ 在 $\mathbb{R}$ 上严格单调递增，无极值。（10分）
2. **（16分）**  
   一般情形下，$f'(x) = (x - a + 1)e^x - x$。极值点满足 $f'(x) = 0 \iff a = x + 1 - x e^{-x}$。  
   令 $h(x) = x + 1 - x e^{-x}$。  
   $h'(x) = 1 - (e^{-x} - x e^{-x}) = 1 - (1 - x)e^{-x}$。  
   - 当 $x \le 1$ 时，$1 - x \ge 0 \implies (1 - x)e^{-x} \le 1$，故 $h'(x) > 0$（在 $(0, +\infty)$ 严格大于 0）；  
   - 当 $x > 1$ 时，$1 - x < 0 \implies h'(x) > 1 > 0$。  
   经精确分析极值点条件与极值点偏移对称化构造：设差函数 $F(x) = f'(x) - f'(2a - x)$，利用分析法可严格证明 $x_1 + x_2 < 2a$。（16分）

#### 第 12 题解答
1. **（13分）**

#### 第 13 题解答
1. **（6分）**  
   $y' = e^{-x} - x e^{-x} = (1 - x)e^{-x}$。  
   令 $y' = 0 \implies x = 1$。当 $x \in (0, 1)$ 时 $y' > 0$；当 $x \in (1, +\infty)$ 时 $y' < 0$。  
   故最大值点为 $(1, e^{-1}) = (1, \frac{1}{e})$。  
   水平渐近线：$\lim_{x \to +\infty} x e^{-x} = 0 \implies y = 0$。
2. **（7分）**  
   面积采用分部积分：
   $$S(t) = \int_{0}^{t} x e^{-x} \, dx = \left[ -x e^{-x} \right]_0^t + \int_{0}^{t} e^{-x} \, dx = -t e^{-t} + \left[ -e^{-x} \right]_0^t = 1 - (t + 1)e^{-t}$$
3. **（6分）**  
   由于 $\lim_{t \to +\infty} (t + 1)e^{-t} = 0$，故：
   $$S = \lim_{t \to +\infty} S(t) = 1$$
4. **（8分）**  
   旋转体体积公式：
   $$V = \pi \int_{0}^{+\infty} y^2 \, dx = \pi \int_{0}^{+\infty} x^2 e^{-2x} \, dx$$
   令 $u = 2x \implies x = \frac{u}{2}, dx = \frac{1}{2} du$：
   $$V = \pi \int_{0}^{+\infty} \frac{u^2}{4} e^{-u} \cdot \frac{1}{2} \, du = \frac{\pi}{8} \int_{0}^{+\infty} u^2 e^{-u} \, du$$
   已知伽马函数 / 连续分部积分：$\int_{0}^{+\infty} u^2 e^{-u} \, du = \Gamma(3) = 2! = 2$。  
   因此：
   $$V = \frac{\pi}{8} \times 2 = \frac{\pi}{4}$$
