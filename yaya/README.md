# Yaya's 高等数学与统计练习工作室 🎓✨
### Pre-University, Calculus & Statistics Exam Studio

为高三毕业冲刺、大学入学考试（高考压轴题、名校自主招生/拔高先修、AP Calculus/Statistics、IB Math HL 及大学预科课程）设计的交互式试卷生成器与在线练习系统。

---

## 🌟 快速使用指南 (Quick Start)

1. 双击直接在任意现代浏览器（Chrome、Safari、Edge、Firefox）中打开 [`index.html`](./index.html)。
2. 在左侧面板选择 **⚡ 快捷预设套卷**，或根据复习需求自定义**专题考点**、**难度等级**、**题目数量**、**分栏列数**与**字号大小**。
3. 自由切换两种学习模式：
   - **🖨️ 试卷排版与打印预览 (Printable View)**：自动分页、带标准考场抬头、草稿答题书写区与独立的答案速查/评分标准页，点击 **🖨️ 打印试卷** 或快捷键 `Ctrl/Cmd + P` 即可一键输出高品质 A4 / PDF 试卷。
   - **💻 在线互动实战练习 (Practice Online)**：支持数字、分数与代数结论在线输入、客观题即时评分、考试计时器、考点提示（Hints）与分步解析（Step-by-Step Solutions）随时展开，获得高分触发彩色纸屑庆祝动画！

## 📚 涵盖考点与专题内容

### 1. 微积分核心专题 (Calculus)
- **导数与极值分析**：导数运算法则、切线方程、三次函数单调区间与极值最值、拐点与中心对称性。
- **函数零点与不等式放缩**：参变分离法、开区间端点极限、泰勒展开二阶放缩、基础切线不等式（$e^x \ge x + 1, \ln x \le x - 1$）。
- **定积分计算与几何应用**：换元积分法（代换法）、分部积分法、降幂公式、平面图形面积微元、绕坐标轴旋转体体积与反常积分。

### 2. 概率与数理统计专题 (Probability & Statistics)
- **离散型随机变量**：超几何分布与二项分布辨析、期望与方差性质（$E(aX+b) = aE(X)+b$）、期望收益经济决策模型。
- **连续型分布与正态分布**：标准正态变换 $Z = \frac{X-\mu}{\sigma}$、对称轴性质、工业质量控制 $3\sigma$ 准则。
- **统计推断与独立性检验**：$2 \times 2$ 列联表构建、卡方统计量 $\chi^2 = \frac{n(ad-bc)^2}{(a+b)(c+d)(a+c)(b+d)}$ 计算与显著性水平决策。
- **线性回归与非线性建模**：最小二乘估计斜率 $\hat{b}$ 与截距 $\hat{a}$、相关系数 $r$、样本中心点 $(\bar{x}, \bar{y})$、指数增长模型对数线性化。
- **大学数理统计衔接**：联合似然函数 $L(\theta)$、对数似然方程与参数最大似然估计（MLE）。

## 🖨️ 打印与排版特性

- **A4 / Letter 标准试卷排版**：带完整考场信息栏（姓名、准考证号、分值、时间）。
- **草稿答题书写区**：每道题预留规整演算区域，方便纸质书写。
- **环保节纸答案速查表 + 步骤解析页**：独立分页输出客观题速查矩阵与主观题分步赋分细则。
- **纯净打印模式 (`@media print`)**：自动隐去所有侧边栏、网页导航与操作按钮，输出清晰无杂质的黑白/高清晰度试卷。
