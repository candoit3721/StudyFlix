## 🔑 Answer Key & Detailed Step-by-Step Solutions

1. **$\frac{19}{24}$** — $\text{LCD} = 24$: $\frac{9}{24} + \frac{10}{24} = \frac{19}{24}$.
2. **$\frac{7}{12}$** — $\text{LCD} = 12$: $\frac{10}{12} - \frac{3}{12} = \frac{7}{12}$.
3. **$3\frac{14}{15}$ (or $\frac{59}{15}$)** — $\frac{7}{3} + \frac{8}{5} = \frac{35}{15} + \frac{24}{15} = \frac{59}{15} = 3\frac{14}{15}$.
4. **$2\frac{5}{6}$ (or $\frac{17}{6}$)** — $\frac{9}{2} - \frac{5}{3} = \frac{27}{6} - \frac{10}{6} = \frac{17}{6} = 2\frac{5}{6}$.
5. **$\frac{3}{4}$** — $\frac{4 \times 15}{5 \times 16} = \frac{60}{80} = \frac{3}{4}$.
6. **$4$** — $\frac{7}{2} \times \frac{8}{7} = \frac{56}{14} = 4$.
7. **$\frac{5}{6}$** — $\text{Keep, Change, Flip: } \frac{3}{4} \times \frac{10}{9} = \frac{30}{36} = \frac{5}{6}$.
8. **$9$** — $\frac{6}{1} \times \frac{3}{2} = \frac{18}{2} = 9$.
9. **$\frac{1}{8}$** — $\frac{5}{8} \times \frac{1}{5} = \frac{5}{40} = \frac{1}{8}$.
10. **$2$** — $\frac{12}{5} \div \frac{6}{5} = \frac{12}{5} \times \frac{5}{6} = \frac{60}{30} = 2$.
11. **$63.525$** — $45.680 + 17.845 = 63.525$.
12. **$53.76$** — $82.50 - 28.74 = 53.76$.
13. **$65.38$** — $100.00 - 34.62 = 65.38$.
14. **$15.3$** — $425 \times 36 = 15300$, move decimal 3 places left $\rightarrow 15.300 = 15.3$.
15. **$0.12$** — $48 \times 25 = 1200$, move decimal 4 places left $\rightarrow 0.1200 = 0.12$.
16. **$12$** — Shift decimal 1 place: $144 \div 12 = 12$.
17. **$8.2$** — $32.8 \div 4 = 8.2$.
18. **$90$** — Shift decimal 1 place: $450 \div 5 = 90$.
19. **$0.6$** — $3 \div 5 = 0.6$.
20. **$\frac{7}{20}$** — $\frac{35}{100} = \frac{7}{20}$.
